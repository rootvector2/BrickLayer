# BrickLayer Protocol MVP Scope

## Objective
Deliver a functional MVP that demonstrates tokenized real estate ownership,
on-chain asset representation, and a compliant off-chain user flow.

## In-Scope Features
- Tokenized real estate asset smart contract (ERC-20 / ERC-721 based)
- Asset minting and ownership transfer
- User onboarding with KYC/AML verification (integration-ready)
- Wallet-based authentication
- Asset listing and basic portfolio view
- Admin dashboard for asset management

## Out of Scope (Post-MVP)
- Secondary market trading
- Cross-chain interoperability
- DAO governance
- Advanced analytics and AI valuation
- Mobile application

## Target Users
- Early crypto-native investors
- Accredited investors (jurisdiction-dependent)
- Internal admin operators

## MVP Success Criteria
- Assets can be minted, assigned, and viewed
- Ownership is provably on-chain
- End-to-end flow runs in staging and production
